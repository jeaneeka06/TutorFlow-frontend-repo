# TutorFlow 🎓

TutorFlow is an AI-powered tutoring platform designed to help students learn, manage their tutoring sessions, and get personalized assistance.

## 🚀 Live Demo

[View TutorFlow Live](https://tutor-flow-frontend-repo.vercel.app/)

## ✨ Features

- 🤖 AI-powered tutoring assistant
- 📚 Student dashboard
- 📅 Tutoring session bookings
- 👤 User profile
- 🧑‍🏫 Services page
- 💬 AI chat functionality
- 📊 Dashboard with student information
- 🔐 User authentication
- 💾 MongoDB database

## 🛠️ Technologies Used

### Frontend
- React
- JavaScript
- CSS
- React Calendar
- Chart.js

### Backend
- Node.js
- Express.js
- MongoDB
- OpenAI API

### Deployment
- Frontend: [Vercel](https://tutor-flow-frontend-repo.vercel.app/)
- Backend: Render
- Database: MongoDB Atlas

## 🤖 AI Tutor

TutorFlow uses the OpenAI API to provide students with an interactive AI tutoring assistant.

Students can ask questions and receive AI-generated explanations and assistance directly through the platform.
